## Architecture

The website uses:

- React
- Vite
- React Router
- Normal CSS
- Centralized content config in `src/config/siteData.js`

## Lead Generation

The site includes visible WhatsApp and quote request buttons, pre-filled WhatsApp messages per service page, and quote forms with these fields:

- Name
- Phone
- Email
- Area
- Service needed
- Job description
- Urgency
- Preferred contact method

Form submissions currently log to the browser console until a real form service or backend is connected.
